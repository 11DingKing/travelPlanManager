## 题目内容

旅行计划管理器开发一个旅行计划管理器，帮助用户规划旅行行程，包括目的地、日期、行程安排（如 “Day1：景点游览”）、住宿信息及携带物品清单。具体要求如下：1)实现旅行计划数据的增删查改功能，支持按目的地 / 日期筛选查询历史计划。2)使用字典或类表示计划信息，“行程安排” 支持按天排序，“物品清单” 支持添加 / 删除 / 标记 “已打包”。3)提供界面，支持添加景点备注（如门票价格、开放时间），住宿信息包含地址与电话。4)可添加 “预算计算” 功能，录入交通、住宿、餐饮费用，自动汇总旅行总预算1. 基础知识：包括Python语言的格式规范、变量、数据类型、运算符的使用等。 
2. 数据类型及操作：数值、字符串、列表、元组、字典等数据类型的灵活使用。 
3. 流程控制语句：对条件语句（if-else）、循环语句（for、while）等流程控制语句的使用。 
4. 函数与模块：包含函数的定义、调用和参数传递，以及内部模块的使用。 
5. 文件操作与数据处理：包括对文件的读写、目录管理。 
6.面向对象：类的定义、对象的创建与使用；类的属性和方法的应用；能将封装、继承和多态应用到程序开发中。我只需要一个day.py的页面，然后页面只要一个不需要这么多页面

## 功能特性

- 旅行计划的增删查改
- 按目的地/日期筛选查询
- 每日行程安排（按天排序）
- 景点管理（门票价格、开放时间、备注）
- 住宿信息管理（地址、电话）
- 物品清单（添加/删除/标记已打包）
- 预算计算（交通/住宿/餐饮/门票/其他）

## 界面说明

程序采用左右分栏布局：
- 左侧：固定显示操作菜单
- 右侧：显示操作结果和详细信息
